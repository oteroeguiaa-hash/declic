Balade 3D à Woluwe

Promène-toi à pied dans ta rue, les rues d'à côté et le parc Georges-Henri, sur les vraies images 3D de Google Maps.

Elle reste uniquement dans ton navigateur.
Comment avoir la clé Google (5 min, gratuit pour un usage perso)
  1. Va sur console.cloud.google.com et crée un projet.
  2. Menu « API et services » → « Bibliothèque » → cherche Map Tiles API → Activer.
  3. Google demande d'ajouter un moyen de paiement (compte de facturation). Le quota gratuit mensuel couvre largement des balades perso.
  4. « API et services » → « Identifiants » → « Créer des identifiants » → Clé API. Copie-la ici.
  5. Conseillé : restreins la clé à « Map Tiles API » et à l'adresse de ton site.
Commandes
  1. Clic dans l'image pour tourner la tête à la souris (Échap pour sortir).
  2. ZQSD / WASD / flèches : marcher. Maj : courir. Espace : sauter.
  3. 1 2 3 4 (ou V) : vitesse ×1, ×2, ×5, ×10. On ne traverse pas les bâtiments, même vite.
  4. F : mode drone (Espace monte, C descend). T : les lieux. H : ma rue. P : parc Georges-Henri.

La météo et l'heure sont celles de Woluwe en ce moment : pluie, neige, brouillard, nuit…

Sur téléphone : tiens-le à l'horizontale. Pouce gauche pour marcher, glisse à droite pour regarder, rond en bas à droite pour sauter.
